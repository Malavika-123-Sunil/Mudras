# Asamyuta Hasta Mudras

AI-powered Bharatanatyam Mudra Recognition System using Computer Vision and MediaPipe.

## Overview

Mudras is a real-time hand gesture recognition system designed to identify classical Bharatanatyam mudras using AI and computer vision.

The system detects hand landmarks through a webcam, analyzes finger positions, and predicts the corresponding mudra in real time.

## Features

- Real-time hand tracking
- Mudra recognition using AI
- MediaPipe hand landmark detection
- Webcam-based interaction
- Voice output for detected mudras
- Lightweight and fast prediction system

## Tech Stack

- Python
- OpenCV
- MediaPipe
- Scikit-learn
